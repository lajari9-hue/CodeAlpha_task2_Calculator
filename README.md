CodeAlpha Task 2 - Calculator
A modern, responsive calculator web application built using HTML, CSS,
and JavaScript as part of the CodeAlpha Frontend Development Internship.
Features
- Addition, subtraction, multiplication, and division
- Percentage/remainder operation
- Clear and delete buttons
- Decimal number support
- Real-time calculation display
- Keyboard support
- Responsive design for different screen sizes
- Modern user interface with hover and click effects
- Division-by-zero error handling
Technologies Used
- HTML5
- CSS3
- JavaScript
Project Structure
CodeAlpha_task2_Calculator/
├── index.html
├── style.css
├── script.js
└── README.md
How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in a browser.
4. For the best development experience, use the Live Server extension
   in VS Code.
